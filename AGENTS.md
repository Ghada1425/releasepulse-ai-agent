# ReleasePulse engineering contract

Developed by Ghada Alaidi for the SDAIA Academy Agentic AI Systems Engineering capstone.
Keep analytics deterministic, synthetic data only, and credentials in environment variables.
Never add writes, arbitrary code, SQL, shell execution, or network destinations to agent tools.
All persistent report exports require a UI approval bound to exact bytes; rejection consumes the proposal.
Preserve this protection in both A and B. Run `uv run pytest` and `uv run ruff check .` after changes.
Label scripted model tests separately from live model evaluations. Never invent results.
